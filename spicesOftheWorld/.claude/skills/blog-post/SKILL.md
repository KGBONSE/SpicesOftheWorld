## Before writing

Read `content/2026-09-23-mokola-market-yaji-blog.md` first — that's Kofi's adopted real example, the primary voice anchor for this skill (edited by Kofi, not just AI-drafted brand voice). Then read `agents/marketing-team.md` (shared rules: voice, positioning, facts, compliance) and `docs/brand-voice.md`, every session. If the post is about a specific episode, region, or blend, also read the matching file in `scripts/` and any relevant `knowledge-base/` file. Check `docs/product-catalog-notes.md` for which SKUs are actually published before writing about a product.

## Input

If not already given, ask what the post is about (episode / region / blend) and what source material to draw from (an episode script, a knowledge-base file, or a pasted summary). Do not invent facts beyond the source material.

## What to produce

An 800-1500 word post: hook, origin, history, the blend, a dish, and a link to the product. The full recipe stays in the post, same as it does in the video — the CTA sells the ready-made blend and a printable card, it never gates the recipe.

Also produce:
- 3 SEO title/meta description options
- A short product description and a long description (memory-first voice, but lead with what the product actually is in the first sentence, for search)
- Image alt text suggestions if relevant images are named in the source

## Rules

- Cite Dr Farrimond by name wherever a fact comes from *The Science of Spice*; paraphrase, never quote.
- "Research suggests..." is editorial context only — never a product health claim. Flag anything borderline.
- Put `[VERIFY ALLERGENS AGAINST SUPPLIER]` on any product mention; never state allergens as confirmed.
- Only write about dry blends and chilli oils that are actually published. If the product's status is unclear, say so rather than assuming.
- Southeast Asia and Europe have no episodes yet — don't invent content for those regions.

## Save

Save to `content/YYYY-MM-DD-<slug>.md`. Never publish it. End with a short "Needs Kofi" list for anything unverified or missing.

## Learning from Kofi's edits

If Kofi edits `content/2026-09-23-mokola-market-yaji-blog.md` (or adopts a different post as his real example later), re-read it before the next post — his edits are the most current, most authoritative voice sample, ahead of `docs/brand-voice.md`.
