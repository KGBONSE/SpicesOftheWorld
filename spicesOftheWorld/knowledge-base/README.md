# Knowledge Base

Paraphrased content from Dr Stuart Farrimond's *The Science of Spice*
(DK/Penguin Random House, 2018), recovered from prior chat sessions and
imported here. Every fact is paraphrased, not quoted — the book is cited
on camera as the source, never read verbatim.

## Structure

- **`regional/`** — 7 files, one per continent/region (Africa, Middle
  East, South Asia, Southeast Asia, East Asia, Americas, Europe). ✅
  Complete. Each covers sub-region breakdowns, trade/colonial history, a
  local blend recipe, and cross-continent links. Primary source for
  episode segments 1–2 (personal hook, geography/history).

- **`spice-profiles/core-profiles-master.md`** — 9 spices, full
  botany/history/blending-science profiles: Cinnamon, Cassia, Saffron,
  Poppy, Ajwain, Celery Seed, Turmeric, Fenugreek (Clove: history only,
  blending science still missing).

- **`spice-profiles/by-flavour-compound/`** — 41 more spices, organized
  by the book's own flavour-compound groupings (sweet warming phenols,
  warming/fragrant/earthy/penetrating/citrus terpenes, sweet-sour acids,
  fruity aldehydes, toasty pyrazines, sulphurous compounds, pungent
  compounds), plus `cross-reference-notes.md`. This is the recovered
  "batches 2–8" content — **~50 of ~52 book spices are now covered
  between the two spice-profiles sources.**

- **`recipes/`** — `world-of-spice-recipes.md` (11 worked recipes from
  the book) plus `by-flavour-compound-batch/` (7 more recipes tied to the
  flavour-compound batch above, several with direct African relevance —
  West African Peanut Curry, etc).

- **`compound-reference/spice-compound-pairing-reference.xlsx`** —
  3-tab spreadsheet (Spice Overview / Pairing Reference / Coverage
  Notes) for programmatic lookup. Covers the same 9 spices as
  `core-profiles-master.md` only — the book's full ~50×100 compound
  matrix (pp.214–217) was **not** transcribed, since reading exact
  shading from screenshots at that scale isn't reliable and a
  spreadsheet with silently-wrong cells would mislead the agent. For
  anything not in these 9, ask for a targeted check against the original
  photos rather than assuming the sheet has it.

- **`superseded/`** — an earlier partial profiles file (Cinnamon/
  Cassia/partial-Clove only), fully absorbed into
  `core-profiles-master.md`. Kept for audit trail only — **do not use
  for new work.**
