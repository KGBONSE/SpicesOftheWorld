# Fudi People — Brand Voice Profile

Working reference for the Script Writer agent and any manual drafting.
Built from analysis of Kofi's own narration recordings and a written
narration passage.

## Core stylistic signatures

- **Memory-first openers** — segments open on a personal memory or sensory
  detail, before pivoting to fact or history. Emotion leads, information
  follows.
- **Adjective stacking** — descriptive passages typically stack 2–3
  adjectives rather than one ("warm, dusty, familiar" rather than just
  "warm").
- **Recurring metaphor** — "planted the seeds for…" used as a bridge between
  personal/historical moments and their present-day consequences.
- **Trailing list-closes** — emotionally weighted passages often end on a
  short trailing list rather than a single closing sentence, giving a sense
  of accumulation.

## Tone

Warm, personal, rooted in specific place and memory (Mokola Market, Accra;
the Sidcup farm) rather than generic food-history narration. History and
spice science are always told through Kofi's own lived connection to them,
not as detached facts.

## How to use this doc

When drafting or reviewing a script:
1. Check the opening line — does it start on memory/sense, not fact?
2. Check adjective density in descriptive passages
3. Look for a natural place to use the "planted the seeds for…" bridge if
   the passage is transitioning from past to present
4. On emotional beats, consider a trailing list-close rather than a tidy
   single sentence

## Maintenance

Update this file as new voice recordings are analysed. It's the pattern
that matters — there's no need to track or reference specific source
recording files here.
