# Africa spice sourcing tools

Two standalone HTML pages covering ingredient sourcing for the 8 live
Africa-range blends (Yaji, Yassa, Niter Kibbeh, Pepper Soup Spice,
Harissa, Pilau Masala, Mbongo Mix, Durban Curry Masala), pulled from each
episode script's own `## 5. The Blend` section — nothing invented. Both
share the same 32-ingredient dataset (31 to buy, 1 already grown on the
Sidcup farm); open either file directly in a browser.

- **`spice-ledger.html`** — interactive pantry checklist. Tick off what
  you already have; the shopping list narrows to what's left, ranked by
  how many blends need it. State is saved per-browser via `localStorage`.
- **`spice-manifest.html`** — printable reference document (Print/Save as
  PDF button included): the full buying list grouped by category, plus a
  blend-by-blend breakdown with prep notes and ratio status.

Both were built and published 2026-09 as Artifacts (claude.ai) before
being copied in here for version control; the published links may still
be live but this repo copy is the source of truth going forward.

**Still open:** only Yaji has a drafted starter test-batch ratio — the
other 7 blends give an ingredient list, not internal proportions, so test
a small batch of each before scaling to a sellable size (see each
episode script's own Blend section for the "worth test-cooking" notes).
Chilli oil (Africa/East Asia/South Asia) isn't covered here — different
process (fresh chilli infused in oil, not a dry mix) and no recipe is
written down in this repo yet.
