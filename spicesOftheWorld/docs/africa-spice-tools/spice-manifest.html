Before you scale up

  1. Test batches first. Only Yaji has a drafted starter ratio — the other 7 give an ingredient list, not proportions. Mix small, taste, adjust, before committing to a sellable-size run.
  2. Substitutes are real options, not compromises. Korarima ↔ cardamom, mbongo ↔ black cardamom, njangsa ↔ unsalted peanuts, calabash nutmeg ↔ regular nutmeg — swap in whichever is easier to source without changing the blend's identity.
  3. Chilli oil isn't on this list. The 3 named chilli oils (Africa, East Asia, South Asia) are a fresh-chilli-in-oil process, not a dry mix — a separate manifest once the recipe's written down.
  4. Allergens to flag on packaging: mustard (Yassa) and, if using the peanut substitute, peanuts (Mbongo Mix).
